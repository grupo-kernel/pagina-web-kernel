# Módulo Perfiles científicos

Renderiza un directorio científico desde `core/data/researchers.v2.json`.

## Archivos

- `scientific-profiles-renderer.mjs`: renderizador compartido.
- `scientific-profiles.css`: estilos aislados y responsive.
- `preview.html`: vista previa controlada.

## Selección directa

La vista previa admite:

- `preview.html#alicia-cordero`
- `preview.html?investigador=juan-torregrosa`

El módulo no está conectado a producción.
